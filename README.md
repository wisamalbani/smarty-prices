# صفحة أسعار سمارتي (QR)

صفحة ثابتة تعرض سعر أي مادة بالليرة السورية عند مسح رمز QR.

## تفعيل GitHub Pages (مرة واحدة، 30 ثانية)
1. افتح المستودع: https://github.com/wisamalbani/smarty-prices
2. Settings → Pages (من القائمة الجانبية)
3. Source: **Deploy from a branch** — Branch: **main** — Folder: **/ (root)** → Save
4. بعد دقيقة تقريباً تصبح الصفحة متاحة على:
   `https://wisamalbani.github.io/smarty-prices/`

## روابط الاستخدام
- سعر مادة: `https://wisamalbani.github.io/smarty-prices/?c=رمز_المادة`
- بحث: `https://wisamalbani.github.io/smarty-prices/?q=كلمة`

## محتوى الـQR للطباعة
`https://wisamalbani.github.io/smarty-prices/?c=` + رمز المادة
